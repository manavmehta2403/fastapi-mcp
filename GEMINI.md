# Antigravity Git & Workflow Rules

## Mandatory Pull Request & Branching Policy
- **Never commit directly to `main`**.
- **Never push directly to `main`**.
- **Always use Pull Requests (PRs)**: All modifications, refactors, and feature additions must take place on dedicated branches (e.g. `feature/...`, `fix/...`) and be merged via PRs.
- **Strict Verification Gate**: Never push to any remote repository or publish packages without explicit user instruction.
